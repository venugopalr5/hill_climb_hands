# 🏎️ Hill Climb Hands

A Hill Climb Racing-style game controlled using hand gestures through a webcam.

## 🎮 Features

- ✋ Open palm → Gas
- ✊ Fist → Brake
- ✌️ Two fingers → Coast
- ↔️ Tilt hand left/right → Rotate the car in the air
- ⌨️ Keyboard controls available as fallback
- 📷 Real-time hand tracking using webcam

## 🛠️ Technologies

- Python
- Pygame
- Pymunk
- OpenCV
- MediaPipe
- NumPy
